# 🏁 F1 Race Strategy Predictor: The Reactive Physics Engine

## 🌟 Project Overview

The **F1 Race Strategy Predictor** is an advanced simulation tool designed to replicate the chaotic and complex nature of a Formula 1 Grand Prix. It goes far beyond static calculations by integrating a **Reactive Physics Engine** and **Monte Carlo methodology** to predict race outcomes, optimal strategies, and crucial risk factors.

This engine processes data from practice sessions, incorporates historical performance trends, and simulates real-world race events (like Safety Cars and tire degradation cliffs) to deliver highly realistic and actionable predictions.

---

## 🔬 Technical Depth & Core Features

### 🧠 Reactive Strategy Engine

The most critical component. It models real-time decisions, not just pre-calculated optimal paths.

* **Safety Car (SC) Probability:** A random variable is introduced based on historical track data to trigger SC or VSC deployments, forcing the strategy engine to calculate pit stop deltas at reduced cost ($\approx 8s$) and penalize unlucky cars.
* **Tire Cliff Detection:** The engine constantly monitors the predicted degradation slope. If a car is pushing too hard and exceeds a calculated threshold (e.g., $0.15s/lap$ degradation increase), the driver is forced to pit early, simulating the dramatic loss of performance known as "the cliff."

### 📈 Predictive Modeling

| Component | Data Source | Rationale |
| :--- | :--- | :--- |
| **Driver Form Index** | Last 5 Races (R) | A normalized index that adjusts a driver's base pace ($\pm$ percentile) based on their recent finishing performance, capturing current momentum or slump. |
| **Session Fusion** | FP1, FP2, FP3 | Normalizes practice pace across all sessions (correcting for track evolution) to build a robust, multi-compound tire degradation model for long-run pace. |
| **Monte Carlo (MC)** | $N$ Simulations | Runs hundreds of trials per driver to provide a distribution of results. This yields the average finishing time and, crucially, the **Volatility ($\pm$ Range)** metric to quantify strategic risk. |
| **Starting Grid** | Official Q/R Data | Fetches the actual starting order to accurately model the **traffic penalty** applied to the first few laps of the simulation. |

## 📊 Results Visualization

The application provides clear, actionable graphical results:

### 1. Race Trace (Gap Chart)

Visualizes the time gap between the top 10 drivers throughout the race, illustrating where overtakes and pit stops occur. Driver lines are consistently color-coded by their respective F1 teams.

### 2. Time Volatility (Violin Plot)

Plots the distribution of finish times generated by the Monte Carlo runs.
* **Narrow Distribution:** High confidence in the predicted average time.
* **Wide Distribution:** High volatility and risk associated with the strategy/driver.

### 3. Risk Summary

Bar charts displaying the calculated DNF Probability and the breakdown of each driver's optimal tire strategy (e.g., `S 18 / H 42`).

## 🛠️ Installation and Setup

### Prerequisites

* Python 3.8+
* Packages: `streamlit`, `pandas`, `numpy`, `plotly`, `fastf1`, `scikit-learn`

### Setup Instructions

1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/fadiz911/Formula-1-Race-Strategy-Predictor.git
    cd Formula-1-Race-Strategy-Predictor
    ```

2.  **Initialize Environment & Dependencies:**
    ```bash
    python -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt 
    ```

3.  **Run the Application:**
    Choose your preferred interface:

    | Interface | Command | Description |
    | :--- | :--- | :--- |
    | **Web App (Interactive)** | `streamlit run app.py` | Access sliders for configuration (Safety Car Risk, Race Selection). |
    | **Console (Non-Interactive)** | `python main.py` | Runs simulation with predefined settings and prints a markdown leaderboard to the terminal. |
